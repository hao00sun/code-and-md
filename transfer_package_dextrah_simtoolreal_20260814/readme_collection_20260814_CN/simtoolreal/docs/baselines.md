# SimToolReal Baseline 中文说明

Baseline 文档介绍不依赖完整 RL policy 的对比方法。

## 常见 baseline

```text
固定抓取策略
运动学重定向
轨迹优化
IK / collision-aware IK
pyroki 相关规划方法
```

## 用途

```text
1. 作为 RL policy 的对比基线
2. 检查任务几何是否合理
3. 生成可行的初始化轨迹或演示轨迹
4. 诊断机器人运动学限制
```
